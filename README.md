# Urdu Translation + Text-to-Speech (TTS) Pipeline

A Python pipeline that:
- Simplifies complex English text.
- Translates to Urdu using Deep Translator.
- Converts Urdu text to speech using ElevenLabs API.

## Features
✅ Text simplification  
✅ English ➔ Urdu translation  
✅ Urdu text-to-speech generation  
✅ ElevenLabs API integration  
✅ Professional folder structure
